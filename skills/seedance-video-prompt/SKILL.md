# Seedance Video Prompt

默认中文交付。只改写已有提示词时，保留其有效结构和未受影响的部分。

## 输入判断

必需：含时间轴或分镜段落的基础剧情，以及至少一张相关角色、道具或场景参考图。

可选输入：目标总时长、画幅、帧率、风格、台词语言、音频要求、转场偏好、已有提示词。缺失时按下列默认处理：16:9、24fps、电影感 3D 动画、无 BGM、只保留剧情中明确存在的台词。不要为了补齐输入而虚构用户没有确认的设定。

## 执行流程

1. **读取剧情证据**：提取角色、道具、场景、动作顺序、情绪变化、台词和声音线索。不新增改变因果的核心剧情。
2. **筛选参考素材**：逐张识别图片主体，只保留剧情实际需要的角色、道具或场景图。
3. **建立角色锚定**：查看保留下来的参考图，记录可跨镜头复用的外观特征：物种、体型、毛色、服装、五官、表情基线、标志物和禁忌差异。按剧情需要和用户给定优先级重新编号为 `@图1`、`@图2`；不要沿用被排除素材留下的空号。
4. **分析时空关系与转场策略**：
   - **同场景/连续动作**：采用 `ACTION MATCH CUT`（动作匹配切镜）、`FOLLOW CUT`（视线引导推进）或 `PUSH IN / PULL BACK`（景别连贯推拉）。
   - **跨时空/跨年龄/跨场景高光切换**：按画面使用 `MATCH DISSOLVE`（图形/构图/姿态匹配叠化）、`CROSS DISSOLVE`（交叉叠化）、`FLARE / BOKEH DISSOLVE`（光晕/光斑/星芒叠化）、`SMOKE DISSOLVE`（烟雾弥散与形体凝聚）、`WIPE / OCCLUSION`（角色/前景遮挡划像）或 `FLASH TRANSITION`（快门定格/闪光）。
5. **拆分镜头**：按秒分配时长，合计等于目标总时长；按模板写明每镜的接入与收尾，使相邻镜头在光影、构图或动作上衔接。
6. **填充模板**：参考图只决定外观，剧情决定入镜内容。动作写清起点、路径、反应与落点，保持角色和道具位置连续。台词保留原文语言、情绪、音量与口型要求；声音对应画面内环境、动作、呼吸和台词。
7. **一致性校验**：核对参考图编号、角色外观、镜头时间、转场类型、空间关系、动作因果、音频和台词；发现冲突时修正提示词后再交付。

## 提示词结构

```md
【风格锁定】
<视觉风格、造型质感、光线氛围、画幅、帧率、运动模糊/景深、摄影质感。>

【参考图锚定】
@图<序号> <文件名/角色名> 作为 <角色名> 视觉锚定（<关键外观特征>），严格保持一致。逐张列出，共 <N> 张参考图。

【音频规则】
No BGM（后期剪辑另配）。仅环境音与关键音效：<按镜头列出>。唯一台词——<角色>：<台词>（<情绪与口型要求>）。

【核心声明】
<一句话概括主角、地点、核心冲突/情感主线、情绪终点和镜头推进方式。>

【硬规则】
- Practical Light only——<说明唯一主光源；用户要求其他光效时改写>。
- DARK AREAS ARE NOT PURE BLACK——暗部保留颜色与纹理。
- 禁止纯侧面 90° 构图。
- 全程手持摄影——<说明晃动强度；用户指定稳定器时改写>。
- 每段镜头只有一个核心动作、一个主运镜，动作关系与因果清晰可追踪。
- 转场衔接规则——<明确同场景的连贯切镜与跨时空的叠化/光影/遮挡过渡策略，禁止非同场景下的生硬跳切>。
- <关键视觉母题/连续性规则>。

【空间布局/Mise-en-scène】
<场景构成、主要光源、前景/中景/背景、主角起点与终点、其他角色或环境元素的动线与布局。>

【运镜与转场】
<N>段连续镜头：<按顺序列出每镜的景别、角度、主运镜及镜头间的转场关系。>

【镜头列表】
镜头1(0—<秒>秒) [转场类型: 如 START: FADE IN / MATCH DISSOLVE]
<Shot size>, <Angle>, <Camera movement>, <Transition Type>
接入：<上一镜头过渡接入状态，首镜头写起始光影与构图。>
构图：<构图规则与主体位置。>
动作：<主体动作、反应、路径和时间关系。>
声音：<具体环境音、动作音、呼吸、台词。>
收尾转场：<本镜头结尾的光影弥散、动作定格、烟雾或构图，为下一镜头预留的过渡锚点。>
节奏：<动作/反应的秒级拆分，最后一项 END。>
...继续写完全部镜头。
```

## 交付格式

默认只输出完整提示词。若用户要求保存文件，写入当前工作区并只返回文件路径。若排除素材，先用一行说明原因；剧情存在关键缺口或参考图无法识别时，同样说明处理方式；无法安全继续时只提出一个关键问题。
