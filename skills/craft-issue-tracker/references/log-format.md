# 日志格式

问题详情顺序：修改日志、原始问题与实际结果、复现步骤、预期结果、原文链接。

日志位于顶部，事件按时间倒序，使用同级三级标题。标题不放时间；标题、正文段落和末尾时间分别为独立 Craft 块，时间写在正文块的行内代码中。

只记录真实发生的创建、迁移、修复等事件。修复轮次记录本轮原因、修复说明、实际提交列表、验证证据（环境、步骤、预期、实际结果、测试及附件）和已收到的用户反馈及时间。一轮可含多个原子提交；验证失败反馈的环境、原因归入对应轮次，同轮反馈最新在前并保留历史。再次修改代码时新开一轮。

时间格式为 `YYYY-MM-DD 星期X 上午/下午h:mm`，使用上下文确认的时区，默认 Asia/Shanghai。原始记录保留其时间精度；缺少时分时注明“原记录未记具体时分”。
