# 视频反推分析规范

## 1. 证据与分镜

1. 先记录总时长、分辨率、帧率、画幅、是否有音轨；拿不到的数据写“未知”，不得用默认值冒充源视频参数。
2. 至少完整查看一次视频，再逐镜检查切点与关键帧。以硬切、叠化、闪白、遮挡、动作匹配、场景或机位明显变化作为镜头边界；同一长镜头内的运镜变化不自动拆镜。
3. 时间码使用 `Shot 01 [00:00.000–00:03.200]`；精度服从可用工具。镜头按顺序编号，区间不得重叠或无故留白，并覆盖完整视频。
4. 先描述证据，再做生成性补全：
   - **直接观察**：画面或音轨明确呈现的对象、动作、颜色、切点、文字和声音。
   - **合理推定**：广角感、柔光、调色倾向等视觉等效判断；用“约、观感、推定”表达。
   - **不可判定**：精确镜头焦距、灯具参数、被遮挡细节、无音轨时的声音等。
5. 人物使用年龄段、可见肤色、脸型、五官、发型、妆容、体态、服装和配饰描述；不要从外貌猜测种族、国籍、宗教、健康等身份属性。
6. 读取文字、Logo、对白前确认清晰度；不确定内容用 `[无法辨认]`，不得补字。专业版可以分析其出现时机与动效，但生成提示词默认泛化具体品牌和台词。

## 2. 快速版：七要素

适合单镜头、短片段、产品展示、Vlog，或用户只想快速得到一段可投喂提示词的情况。

1. **主体**：人物或物品的稳定外观锚点。人物写年龄段、性别呈现、体态、脸型与可见五官、发型、妆容、服装、配饰、情绪气质；物品写尺寸比例、材质、颜色饱和度、表面反光、结构和使用状态；场景主体写空间尺度与标志元素。
2. **动作**：起始姿态 → 运动路径 → 结束姿态；补充速度、力度、重心、手部、视线和微表情。多人时写清各自站位与互动。
3. **场景**：室内外类型、建筑/自然风格、布局、关键陈设，前中后景，时间、季节、天气和氛围。
4. **光影**：自然/人工/混合光，硬/柔/漫射，方向、强度、阴影边缘、轮廓光、眼神光、反射折射与色温。
5. **摄影**：景别、机位、焦段观感、构图、推拉摇移/跟拍/环绕/升降/手持/稳定器、速度、景深、焦点转移和画幅。多镜头补充转场顺序。
6. **风格**：影像类型、色彩关系、暗部/中间调/高光倾向、颗粒、锐度、柔焦与对比度；主体、场景和光影须统一。
7. **画质**：按用户目标写分辨率、帧率和清晰度；未指定时不要伪装为源视频参数。写明动作流畅、比例正确、纹理稳定等质量目标。

没有被视频证据支持的创作补全必须标为“生成建议”。

## 3. 专业版：逐镜十八维

每个镜头依序写全以下维度；某项确实不可见时写“不可判定”，不要用空泛句凑数。

1. 镜头编号与时间码。
2. 主体身份标签与可见外观锚点。
3. 动作轨迹：起点、路径、落点、手部、重心、速度与力度。
4. 微表情与视线：变化节点和方向。
5. 场景空间：内外、风格、布局、陈设。
6. 前中后景关系与纵深。
7. 景别。
8. 机位高度、角度及与主体的相对距离。
9. 焦段观感：广角、标准或长焦及其可见效果。
10. 构图：三分、中心、对称、引导线、框架、对角线等。
11. 景深、虚化范围与焦点转移。
12. 运镜轨迹、稳定方式、速度和变速节点。
13. 光源方向、自然/人工、硬柔、可见光比观感。
14. 色温、暗部/中间调/高光色调。
15. 关键材质、纹理、反射、折射或流动表现。
16. 镜头长度、动作节奏、剪辑节奏与停顿。
17. 与下一镜头的转场；末镜头写“结束”。
18. 可听见的环境声、音效、音乐节拍或对白关系；无法试听时写“不可判定”。

### 每镜头成品提示词

每个 Shot 必须另给：

1. 起始画面：第一帧的主体位置、构图、光色和状态。
2. 主体动作：从起点到落点的完整、连续过程。
3. 摄影机运动：方向、轨迹、速度、稳定方式和焦点变化。
4. 结束画面：最后一帧的构图、动作落点和情绪。
5. 镜头衔接：下个镜头通过动作、视线、构图、光影、声音或遮挡如何接入。
6. 完整提示词：合并上述内容，并继承全局锚定。

## 4. 全局连续性锚定

在专业版提示词前统一定义：

- 主体：脸型、发型、体态、妆容、服装、配饰、产品形态与尺度。
- 空间：场景布局、地标、主体动线、前中后景关系。
- 视觉：画幅、调色、主光方向、影像质感、运动模糊和景深基线。
- 物理：道具位置、接触关系、重力、反射、阴影方向和动作因果。
- 声音：环境底噪、关键音效、音乐节拍、对白与口型要求；只写源视频可听见或用户明确指定的声音。

## 5. 类型专项规则

只加载与视频实际类型匹配的规则；混合类型可组合，但不要重复字段。

### 人物 / 剧情

- 每镜头写情绪起点 → 变化节点 → 情绪终点。
- 多人写站位、距离、朝向和互动；对话写正反打、视线交叉与轴线关系。
- 写出台词密度、停顿或沉默的戏剧功能；不可听清的对白不得补写。

### 产品 / 商业广告

- 每次出现产品时写展示角度、光线打法、材质高光和可见标识。
- 写产品与手或环境的拿起、放下、旋转和使用关系。
- 区分快节奏的情绪驱动与慢节奏的细节展示；标明文字元素的时机和动效。

### 风景 / 旅行

- 写近景清晰度、中景雾化、远景朦胧的大气透视。
- 写自然光时段变化与运镜如何顺应山脊、河流、道路或天际线。
- 分层记录风、水、鸟、人声和寂静；无音频时不推定。

### 音乐 / MV

- 标记切点与拍点、反拍或连续快切的关系。
- 对应前奏、主歌、副歌、间奏的景别、剪辑和色彩变化。
- 仅在可听见时描述 bass drop、旋律上升与闪白、升镜等同步效果。

### 美食 / 手工 / 教程

- 写工作台俯拍布局、工具/材料/成品的空间排列。
- 关键步骤、材质变化和完成瞬间触发特写。
- 精确写手部动作速度、力度、接触点及材料的可见状态变化。

## 6. 模型适配

- 用户指定 Sora、Kling/可灵、Runway、Vidu、Pika 等模型时，保留同一视觉事实，只调整组织方式和该模型已确认支持的参数。
- 模型能力、参数或语法可能变化。需要模型专用语法时，优先使用用户提供的版本说明或当前官方文档；无法确认则明确标为“通用自然语言提示词”，不要发明参数。
- 不把长视频强塞进单次生成限制。若目标模型存在已确认的时长限制，按镜头分段并保留首尾帧和连续性锚点。

## 7. 专业版负面约束

每类都要覆盖，但删除与画面明显无关的条目（例如无人视频不需要牙齿或手指约束）。用清晰禁止项，不写互相冲突的要求。

- **人物一致性**：禁止变脸、肤色漂移、发型突变、服装漂移、配饰消失或变形。
- **肢体与动作**：禁止多指/少指、手指融合或穿模、关节反折、肢体比例失真、动作断裂、身体穿透、不符合动作设定的悬浮。
- **面部与表情**：禁止五官位移、牙齿异常、眼睛大小或视线不一致、表情僵硬、情境错配、口型与语音不同步。
- **场景与物理**：禁止背景闪烁或漂移、物体无故换位、重力/阴影/反射矛盾、透视和尺度错误、材质突变。
- **画面质量**：禁止非刻意模糊或局部失焦、过量噪点或色带、画面撕裂、帧间闪烁、水印、伪文字、乱码、局部清晰度不一致。
- **运镜与时间**：禁止非刻意运镜跳变、卡顿、快进或回放，禁止跨镜光向和色温无理由突变。
