## 写作约束

- 列表用于分析，`完整提示词` 必须是可直接复制的自然语言指令。
- 按“主体与场景 → 起始状态 → 动作过程 → 摄影机 → 光影与材质 → 结束状态 → 质量约束”的顺序组织完整提示词。
- 一个镜头只设一个主要动作和一个主运镜；确有组合运镜时写清先后，不用斜杠堆叠。
- 不重复同一条全局锚定；逐镜只写本镜头的变化量。
