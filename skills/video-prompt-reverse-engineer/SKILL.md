# Video Prompt Reverse Engineer

默认中文交付。目标是把视频中的可观察证据转成可执行的生成指令，并提取视觉语法；不要只复述内容，也不要把推测写成事实。

## 输入与路由

- 必需：可读取的视频文件或可访问的视频页面。只有静帧时，只分析静态视觉并明确无法判断动作、运镜、转场和声音。
- 可选：`快速版` / `专业版`、目标生成模型、目标时长、画幅、帧率、复刻重点。未指定模式时默认快速版；明确要求逐镜头、多镜头复刻、广告/短剧/MV 级拆解时用专业版。
- 未指定目标模型时输出通用提示词并标记“目标模型：通用”；只有用户要求特定语法时才需要确认模型。

## 工作流

1. 读取视频元数据并完整观看；按真实剪辑边界分镜，不按固定秒数硬切。
2. 按分析规范区分观察、推定与不可判定项。
3. 建立跨镜头主体、服装、道具、场景、光色和空间连续性锚点。
4. 按 [分析规范](references/analysis-spec.md) 执行快速七要素或专业十八维拆解，并加载匹配的视频类型专项规则。
5. 按 [输出模板](references/output-templates.md) 交付；专业版必须包含逐镜头提示词、全局锚定和分类负面提示词。
6. 交付前核对时间轴覆盖、动作首尾、转场衔接、一致性、可视化程度及模型适配声明。

## 硬规则

- 风格词必须落实为画面、光色、材质或摄影表现；禁止只写“高级、震撼、电影感”等抽象词。
- 仅学习镜头逻辑和视觉方法。生成提示词应泛化具体人物、品牌、台词与故事，除非用户拥有并明确要求保留自己的素材。
- 不上传视频、不调用外部服务、不复用视频中的私人信息，除非用户另行授权。

最终只交付结果及必要的不确定性说明，不输出内部推理过程。
