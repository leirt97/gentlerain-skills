# 速查表

## 一分钟判断

| 现象 | 更可能是 | 先做什么 |
|---|---|---|
| 婚前就冷淡、劝分手、婚礼上当众羞辱 | 拒绝型 | 停止“了解后就会好”的幻想，和伴侣谈站队 |
| 每次见面都挑你的能力、外表、育儿 | 批评型 | 区分小事与人身攻击；先练四问 |
| 用礼物、机票、房子换顺从 | 控制型/占有型 | 拒绝附带条件的资源，先设经济边界 |
| 要求所有节日、周末、假期都一起过 | 占有型 | 定“相处时长上限”，用交换条件谈 |
| 生活混乱、不断求助、把你卷进危机 | 惹事型 | 区分帮助与解救；先定安全规则 |
| 你一说“不”，对方就哭、病、断绝关系 | 控制型/拒绝型 | 准备后果，不接受内疚绑架 |

## 决策树：这次要不要正面谈？

- 对方行为是否持续、可预测，且已伤害你或孩子？
  - 否 → 当场轻量干预：“你可能没意识到，这句话让我很不舒服。”
  - 是 → 你是否有安全环境与足够支持？
    - 否 → 先写信或低接触，优先安全。
    - 是 → 对方是否“烦人但无恶意”？
      - 是 → 温和指出 + 给台阶 + 重复，不必正式摊牌。
      - 否 → 正式谈话：你的地盘、面对面、只谈行为、带规则与后果。

## 决策规则

1. **当对方攻击你的身份而非行为，不要用改进证明自己**——他们拒绝的是差异，不是缺陷。
2. **当伴侣第一次拒绝，不要判死刑**——焦虑型常需时间；给话术、给具体小步骤，观察他/她是否移动。
3. **当伴侣连“不拆台”都做不到，进入三个选择**——接受、继续协商、结束；不要无限期硬扛。
4. **当你想用离婚逼对方改变，先停下**——它是权衡后的决定，不是谈判筹码。
5. **当对方用断绝关系威胁，先问伴侣“你准备怎样做配偶”**——你无法替伴侣回答忠诚问题。
6. **当规则没有后果，它只是建议**——补上“如果发生，我们会怎么做”。
7. **当对方否认事实，不要争记忆，争行为**——“你可以不认同，但事情确实发生过，而且让我痛苦。”
8. **当对方自居受害者，承认感受但不撤回立场**——“抱歉让你难过，但我必须保护自己。”
9. **当对方推责，只承担你那一半**——“我愿意改我的部分，你愿意承担你的吗？”
10. **当对方打断，先暂停**——“我说完你有足够时间回应；否则另约时间。”

## 权衡矩阵

| 选择 | 短期 | 长期 | 适用条件 |
|---|---|---|---|
| 忍耐/反应不足 | 平静 | 自尊受损、越界升级 | 仅限偶发小事 |
| 当场爆炸 | 释放 | 可信度下降、被指“你才有问题” | 几乎不推荐 |
| 温和设界 | 些许尴尬 | 关系可能改善 | 烦人但无恶意 |
| 正式谈话+后果 | 冲突上升 | 边界清晰，最坏也能止损 | 持续越界、伴侣部分支持 |
| 低接触/断绝 | 内疚、被指责 | 保护婚姻与健康 | 对方持续伤害、拒绝改变 |

## 阈值与默认

- **一次谈话只谈一个主线**；翻旧账会让信息失焦。
- **请求要具体到一件伴侣本周能做的事**；“站我这边”不可执行。
- **规则最多三条**；超过三条，对方记不住，你也执行不了。
- **给改变的时间以周/月计，不以天计**；但要有可观察的第一步。
- **同一越界提醒两次仍无效 → 升级为规则与后果**。
- **对方持续攻击时，先离开现场**；安全永远高于“把话说完”。
- **孩子安全是硬底线**：醉酒、暴力倾向者不得单独与孩子相处。
- **经济援助只给一次应急，不填无底洞**；重复救助等于资助失控行为。

## 识别信号

- 你开始反复解释自己 → 你已进入防御模式，停止辩解。
- 你只敢在伴侣不在场时抱怨 → 需要把问题摆到伴侣面前。
- 你每次见完他们都头痛、胃痛、失眠 → 身体已在报警，别再“忍忍就好”。
- 伴侣回家后对你挑剔 → 他/她可能成了父母的传声筒，问题在“借刀杀人”。
- 对方只在伴侣不在时批评你 → 两面派/借刀杀人，需当面澄清。
- 你总在想“等他们了解我/等有孩子” → 你正抓着七误区之一。
- 你开始觉得“是不是我太敏感” → 先核对事实，再决定是否道歉；不要替对方完成贬低。
