# 第九章：当期待造成伤害

## Core Idea

伤害不只来自对方做了什么，也来自你坚信“事情应该怎样”。三类不切实际的期待会持续制造失望：对自己的期待（我应该刀枪不入）、对伴侣的期待（他/她应该立刻站到我这边）、对伴侣父母的期待（他们应该像父母一样爱我）。放弃幻想不是认输，而是把精力从“为什么他们不给我”转向“我能做什么”。

## Frameworks Introduced

- **期待清单法**：分别写下“不切实际的期待”和“实际的期待”。判断标准不是愿望是否美好，而是它是否符合对方当前的能力、意愿和改变速度。皮特的版本：
  - 不切实际：艾伦会自然把我的喜好放在她父亲之前；让我难受的事也会让她难受；她知道必须改变；她会从我的角度看父亲；她会因为我不舒服而停止取悦父亲；她知道怎么改。
  - 实际：没有改变的必要理由，人会安于现状；要让她明白我的感受，我需要换一种方式；稳固婚姻需要时间、耐心和努力；她减少对父亲的依赖也需要时间。
- **观察者角色**：把自己放到单向玻璃后，看“我对他/她抱了什么期待，这个期待现实吗”。它把情绪反应转成可检验的假设。
- **天使—魔鬼练习**：先想象对方是完美天使（无条件爱你、弥补你所有缺憾），再想象对方是魔鬼（披红斗篷、手持长叉）。两次想象都荒诞，目的是让你看见：对方既不是天使也不是魔鬼，只是个有优点也有缺点的普通人。
- **告别仪式**：放一把空椅子，把“求而不得的期待”放在上面，逐条说出告别的话。它把“我知道该放下”变成一次有仪式感的行动。
- **接受现实三句话**：伴侣父母没有喜欢你、支持你、爱你的义务；他们不会自己改变；他们可能永远达不到你的期待。

## Key Concepts

- **超人期待**：要求自己在被羞辱时保持冷静、不许脆弱、必须完美应对；这会让你把“难过”本身当成失败。
- **伴侣的过渡期**：从“父母的子女”到“配偶”是情感重心的迁移，通常以年计，不会因婚礼瞬间完成。
- **父母替代品**：原生家庭缺爱的人，容易把伴侣父母投射成理想父母；期待越高，普通分歧越像再次被抛弃。
- **非黑即白**：失望后把对方从天使改判为魔鬼，仍是同一个失真机制，只是方向相反。
- **接受 ≠ 原谅**：接受是停止无意义的内耗，不再要求现实符合幻想；它不要求你忘记、亲近或认可对方。
- **拼贴画而非挂毯**：新家庭未必和谐统一，可能只是不同人格与习惯拼在一起；这也可以是可接受的结果。

## Mental Models

- **把期待当合同**：先问“谁签过这份合同？”伴侣父母从未承诺爱你；伴侣也没承诺一夜之间脱胎换骨。
- **把“应该”换成“可能”**：“他们应该尊重我”是底线；“他们应该喜欢我”是愿望。底线要争取，愿望要放手。
- **把改变当能力问题，不只意愿问题**：伴侣可能愿意站队，但尚未具备在父母面前稳住自己的能力；期待要匹配当前能力。
- **把失望当信息**：每次强烈失望都在提示一条未满足的隐藏期待；找到它，比反复控诉更有用。

## Anti-patterns

- **要求自己“别往心里去”**：言语有真实杀伤力；否认脆弱只会让你更自责。
- **要求伴侣立刻觉醒**：越逼他/她表态，越可能把他/她推回熟悉的父母阵营。
- **把伴侣父母当理想父母**：这是把童年缺口交给最不可能填补的人。
- **在天使与魔鬼之间摆荡**：一次失望就全盘否定，会让你看不见对方偶尔的真实善意，也让边界失去精确度。
- **把接受现实等同于忍气吞声**：接受的是“他们暂时不会变”，不是“他们可以继续越界”。

## Worked Example

皮特娶了艾伦，岳父阿特几乎每天打电话，问晚饭吃了什么、买了什么、赚了多少；艾伦做决定前仍习惯先问父亲。皮特一开始坚信：只要他指出岳父的占有欲，艾伦就会恍然大悟，说“是啊，我怎么没发现”，然后立刻减少联系。现实是，艾伦说他“太敏感、太情绪化”，并继续维护父亲。

咨询师没有教他更激烈的辩论，而是让他做两件事。第一，停止在艾伦耳边反复谈她父亲——越谈，她越退回熟悉的舒适区。第二，写下两份清单：不切实际的期待与实际可能的期待（见上）。皮特写完后，语气从“她怎么能这样”变成“我需要换一种方式让她明白，而且这需要时间”。

丽塔的版本发生在婆婆薇薇安身上。她先认定薇薇安是完美祖母——会无条件爱她和孩子、弥补她所有不安；被批评后，又把薇薇安想成阴险魔鬼。天使与魔鬼两幅画面都让她觉得“太蠢了”，她终于说出：“她就是个普通人，有很多优点，也有不少缺点，不是什么神仙。”这不是为薇薇安开脱，而是让丽塔从“她必须完美”与“她一无是处”之间走出来。

莱斯莉则用空椅子完成了告别。她对着椅子说：“我要和你们说再见了，因为你们无法存活，而且消耗了我太多精力……汤米和我们可以建立属于我们自己的新家庭。”她仍然难过，但也松了一口气，并第一次看清：自己一直想从公婆那里得到的东西，其实是要和亲生父母解决的问题。

## Key Takeaways

1. 对自己期待过高，会让你把正常的脆弱当成失败；被伤害时难过是应该的。
2. 伴侣的情感重心迁移需要时间；期待他/她“立刻站队”通常不现实，但可以期待他/她开始行动。
3. 伴侣父母没有爱你的义务；把“喜欢我”当底线，会把你困在无止境的讨好里。
4. 天使与魔鬼是同一种失真的两端；看见“普通人”，边界才立得准。
5. 接受现实是主动结束内耗，不是原谅、遗忘或放弃边界。
6. 你越早停止要求现实符合幻想，越早能把精力用在真正能改变的地方。
